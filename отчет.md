## Лабораторная работа № 2. Формирование недельного меню с помощью генетического алгоритма

**ФИО**: Еремихина Мария Глебовна

**Вариант**: 20

### 1. Цель работы
_Цель работы_ — разработать генетический алгоритм для формирования недельного меню с учётом ограничений по калорийности, стоимости, разнообразию блюд и частоте их использования.
В ходе работы необходимо реализовать дискретное представление решений, операторы генетического алгоритма, методы обработки ограничений и сравнить эффективность различных подходов.

### 2. Представление решения

Одно решение представляет собой меню на семь дней. Каждый день содержит три приёма пищи: завтрак, обед и ужин.
Для представления меню используется вложенный список целых чисел, где каждое число соответствует идентификатору блюда.

**Пример**:
    menu = [
    [12, 5, 8],
    [3, 14, 7],
    [2, 9, 11],
    [6, 1, 15],
    [4, 10, 13],
    [8, 3, 12],
    [5, 7, 14]
    ]

Таким образом, особь содержит 21 ген — по одному на каждый приём пищи в течение недели.
Для каждого приёма пищи выбираются только те блюда, которые соответствуют его типу.

### 3. Функция оценки качества

Для оценки качества меню используется функция приспособленности (fitness). Она учитывает нарушения ограничений задачи.

**Основные ограничения**:

* суточная калорийность должна находиться в диапазоне _от 1300 до 3000_ ккал;
* общая стоимость меню не должна превышать _8000_;
* в меню должно присутствовать не менее _11_ уникальных блюд;
* одно блюдо может использоваться не более _двух_ раз;
* блюда в течение одного дня должны относиться к _разным_ категориям.

Алгоритм минимизирует значение функции приспособленности. Значение 0 означает, что меню удовлетворяет всем ограничениям.

### 4. Отбор родителей

Для выбора родителей используется **турнирный отбор**.
На каждом шаге случайным образом выбирается несколько особей. Среди них родителем становится особь с наименьшим значением функции приспособленности.
Турнирный отбор позволяет сохранять хорошие решения и поддерживать разнообразие популяции.

### 5. Скрещивание

Скрещивание используется для получения новых решений из двух родительских особей.
При скрещивании части меню родителей объединяются, в результате чего потомок получает комбинацию блюд из обоих меню.
После скрещивания потомок может нарушать ограничения задачи, поэтому его качество дополнительно проверяется функцией приспособленности.

### 6. Операторы мутации

Для исследования влияния мутации используются два оператора.

##### 6.1. Случайная мутация

_Случайным_ _образом_ выбираются день и приём пищи. Блюдо в выбранной позиции заменяется другим случайным блюдом, подходящим для этого приёма пищи.
Оператор позволяет исследовать новые варианты меню и поддерживать разнообразие популяции.

#### 6.2. Мутация с учётом категорий

Случайным образом выбираются день и приём пищи. Затем блюдо заменяется на другое блюдо, категория которого отличается от _категорий_ остальных блюд этого дня.
Такой оператор учитывает структуру задачи и помогает уменьшить количество нарушений, связанных с повторением категорий в течение дня.

#### 6.3. Сравнение операторов

Для сравнения операторов необходимо провести серию независимых запусков алгоритма с каждым вариантом мутации.
Сравниваются:

* лучшее значение функции приспособленности;
* среднее значение функции приспособленности;
* количество запусков, в которых найдено допустимое решение;
* время выполнения алгоритма.

### 7. Обработка ограничений

В работе рассматриваются два подхода к обработке ограничений: штрафная функция и восстановление допустимости решения.

#### 7.1. Штрафная функция

При использовании **штрафной функции** каждое нарушение ограничений увеличивает значение функции приспособленности.
Чем больше нарушений содержит меню, тем хуже его оценка. Генетический алгоритм стремится найти решение с минимальным количеством нарушений.
Преимущество этого подхода заключается в простоте реализации. Недостаток состоит в том, что алгоритм может долго исследовать недопустимые решения.

#### 7.2. Восстановление допустимости

**Метод восстановления** пытается изменить меню так, чтобы уменьшить количество нарушений ограничений.
Для этого отдельные блюда заменяются другими допустимыми вариантами. Изменения сохраняются, если они улучшают оценку решения.
Метод позволяет учитывать ограничения непосредственно при изменении меню, однако может увеличивать время выполнения алгоритма.

#### 7.3. Сравнение методов

Для сравнения методов необходимо провести одинаковое количество запусков с одинаковыми параметрами генетического алгоритма.
Результаты сравниваются по следующим показателям:

* доля запусков с допустимым решением;
* лучшее значение функции приспособленности;
* среднее время выполнения;
* среднее качество найденных решений.

### 8. Сравнение с Random Search

Для оценки эффективности генетического алгоритма используется случайный поиск (**Random Search**).
На каждой итерации случайный поиск генерирует новое меню и вычисляет его функцию приспособленности. Лучшее найденное решение сохраняется.
Алгоритм завершает работу при достижении заданного временного ограничения.

Для корректного сравнения генетический алгоритм и случайный поиск должны работать в сопоставимых условиях. В частности, случайному поиску выделяется временной бюджет, соответствующий времени выполнения генетического алгоритма.
Сравнение проводится по лучшему значению функции приспособленности, наличию допустимого решения и времени выполнения.

### 9. Исследование сходимости

В процессе работы генетического алгоритма отслеживается лучшее значение функции приспособленности в каждом поколении.
По этим данным можно построить _график_ зависимости качества лучшего решения от номера поколения.
Если алгоритм работает эффективно, значение функции приспособленности постепенно **уменьшается**. При достижении значения 0 найдено меню, удовлетворяющее всем ограничениям.
Если значение перестаёт изменяться, это может свидетельствовать о замедлении сходимости или преждевременной сходимости алгоритма.

### 10. Заключение

В ходе работы разрабатывается **генетический алгоритм** для решения задачи формирования недельного меню с дискретным представлением особей.
Рассматриваются два оператора мутации, два подхода к обработке ограничений и случайный поиск в качестве базового алгоритма для сравнения.
Экспериментальное исследование позволяет оценить влияние выбранных операторов и методов обработки ограничений на качество решений и время выполнения.

По результатам экспериментов можно определить наиболее эффективный подход к формированию меню, удовлетворяющего заданным требованиям.
