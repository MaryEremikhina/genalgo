# Лабораторная работа №1
## Многомерная оптимизация функции HGBat генетическим алгоритмом
### ФИО: Еремихина Мария Глебовна
### Вариант: 20

### 1. Цель работы

Изучить базовый генетический алгоритм для непрерывной многомерной оптимизации и применить его к минимизации функции HGBat.

Оптимизируемая задача:

$\min_{x \in D} HGBat(x)$, где $d = 7,\qquad x_i \in [-15,15]$

Функция HGBat:
$HGBat(x)= \sqrt{\left| \left(\sum_{i=1}^{d}x_i^2\right)^2- \left(\sum_{i=1}^{d}x_i\right)^2 \right|} + \frac{\frac12\sum_{i=1}^{d}x_i^2+\sum_{i=1}^{d}x_i}{d} +\frac12$

---

### 2. Реализация генетического алгоритма

В качестве представления особи использовался вещественный вектор из 7 координат:
$x=(x_1,\ldots,x_7)$
Размер популяции — **50 особей**, что удовлетворяет требованию задания о размере популяции не менее 30.
Начальная популяция генерировалась равномерно в области:
$[-15,15]^7$

Для каждой особи вычислялось значение целевой функции HGBat. Так как задача является задачей минимизации, меньшему значению функции соответствовало более приспособленное решение.

---

### 3. Отбор родителей

Использовался турнирный отбор.

Для формирования каждого родителя случайно выбирались **3** особи, после чего в качестве победителя выбиралась особь с минимальным значением HGBat.
Размер турнира: $k=3$

Такой способ позволяет отдавать предпочтение более приспособленным особям, сохраняя при этом некоторое разнообразие популяции.

---

### 4. Вещественный кроссовер

Использовался арифметический кроссовер.

Для двух родителей $p_1$ и $p_2$:

$c_1=\alpha p_1+(1-\alpha)p_2$,
$c_2=\alpha p_2+(1-\alpha)p_1$, 
где $\alpha$ выбирается случайно из диапазона $[0,1]$

Вероятность кроссовера: $P_c=0.8$. 
После кроссовера координаты дополнительно ограничивались диапазоном $[-15,15]$.

---

### 5. Вещественная мутация

Использовалась гауссовская мутация как дополнительный пункт:
$x_i' = x_i + N(0,\sigma)$

Базовая вероятность мутации координаты:
$P_m=0.1$

После мутации координаты ограничивались областью допустимых значений с помощью **clipping**:
$x_i' \in [-15,15]$

---

### 6. Элитизм

Для сохранения лучшего решения применялся **элитизм**.
Лучшая особь предыдущего поколения сохранялась и заменяла худшую особь среди потомков.
Это гарантирует, что лучшее найденное решение не будет потеряно при переходе к следующему поколению.

---

### 7. Критерий остановки

В основном эксперименте использовалось фиксированное число поколений:
$N_{gen}=100$

Для каждого поколения сохранялось лучшее найденное значение HGBat.
Для оценки устойчивости алгоритма выполнялось **20** независимых запусков.

---

### 8. Исследование сходимости

Для 20 запусков анализировались:

- минимальное лучшее значение HGBat;
- среднее лучшее значение HGBat;
- максимальное лучшее значение HGBat.

График сходимости позволяет оценить скорость улучшения решения и разброс результатов между независимыми запусками.
Из-за использования элитизма значение лучшего найденного решения не ухудшается с увеличением числа поколений.

---

### 9. Сравнение параметров генетического алгоритма

Были исследованы две конфигурации, отличающиеся только вероятностью мутации:

Для каждой конфигурации выполнялось 20 независимых запусков. Сравнивались средние траектории лучшего значения HGBat.

---

### 10. Сравнение с Random Search

Для сравнения был реализован случайный поиск.
На каждой итерации случайно генерировалась новая точка:
$x_i \sim U(-15,15)$
после чего вычислялось значение HGBat. Запоминалось лучшее найденное значение.

В отличие от генетического алгоритма, Random Search не использует информацию о предыдущих решениях для построения новых точек, 
именно поэтому он показывает **хуже результат**

---

### 11. Почему HGBat является сложной функцией для простого поиска

Функция HGBat является многомерной и нелинейной. При $d=7$ значение функции зависит одновременно от всех координат через сумму координат и сумму их квадратов.
Поэтому изменение одной координаты может влиять на значение функции через общие суммы.
Кроме того, функция содержит квадратный корень и абсолютное значение, что формирует сложный нелинейный рельеф.

Для случайного поиска попадание в область хороших решений происходит случайно и может потребовать большого числа вычислений. Локальный поиск также может зависеть от начальной точки и исследовать только ограниченную область пространства.
Генетический же алгоритм использует комбинацию отбора, рекомбинации и мутации, поэтому одновременно исследует несколько областей пространства поиска.

---

### 12. Дополнительное улучшение: адаптивная мутация

В качестве дополнительного пункта была реализована адаптация масштаба гауссовской мутации.
Вместо постоянного значения $\sigma$ использовалось:

$\sigma_t=1.0\cdot0.99^t$, где $t$ — номер поколения.

Таким образом:

- в начале работы алгоритма мутация имеет больший масштаб;
- по мере увеличения номера поколения масштаб мутации уменьшается;
- в начале алгоритм активнее исследует пространство;
- в конце алгоритм выполняет более мелкие изменения и может точнее дорабатывать найденное решение.
