# Отчёт по лабораторной работе
### 1. Цель работы

Целью лабораторной работы является исследование методов многокритериальной оптимизации на примере настройки игрового искусственного интеллекта для игры Connect Four («Четыре в ряд»).

В рамках работы необходимо реализовать два генетических алгоритма — **NSGA-II** и **Weighted Sum GA**, сравнить их работу и проанализировать полученные результаты с точки зрения качества игровых решений, скорости принятия решений и разнообразия игровой стратегии.
### 2. Постановка задачи
В качестве основы игрового ИИ используется алгоритм **Minimax с альфа-бета отсечением**. Он позволяет выбирать оптимальный ход, анализируя возможные продолжения игры на заданную глубину.

Для настройки игрового агента используются генетические алгоритмы. Каждая особь популяции представляет собой набор параметров, определяющих поведение игрового ИИ:
* `weights` — три весовых коэффициента эвристической функции;
* `depth` — глубина поиска алгоритма Minimax.

Таким образом, особь имеет следующий вид:
`{"weights": (w1, w2, w3), "depth": depth}`

В ходе эволюционного процесса генетический алгоритм изменяет эти параметры с помощью операций скрещивания и мутации, стремясь получить более эффективного игрового агента.
Для оценки особей используется фиксированный соперник со следующими параметрами:

* веса эвристической функции: `(2.0, 3.0, 4.0)`;
* глубина поиска: `3`.

Использование фиксированного соперника позволяет сравнивать игровые агенты в одинаковых условиях.
### 3. Критерии оптимизации
В работе рассматриваются три критерия, которые характеризуют разные стороны качества игрового агента.

**1. Win Rate — доля выигранных партий.**

Показывает, какую часть сыгранных партий агент завершил победой. Чем выше значение данного критерия, тем эффективнее агент справляется с поставленной игровой задачей.

Цель оптимизации — максимизация Win Rate.

**2. Average Decision Time — среднее время принятия решения.**

Показывает, сколько времени в среднем требуется игровому агенту для выбора одного хода. Данный показатель зависит от глубины поиска Minimax и количества рассматриваемых игровых состояний.
Чем меньше время принятия решения, тем быстрее работает игровой агент.

Цель оптимизации — минимизация Average Decision Time.

**3. Strategy Diversity — разнообразие игровой стратегии.**

Данный критерий позволяет оценить, насколько разнообразные ходы выбирает игровой агент в различных игровых ситуациях.

Для его расчёта используется набор из `100` тестовых игровых позиций. Для каждой позиции определяется выбранная агентом колонка. Затем рассчитывается энтропия распределения выбранных колонок, нормированная на максимально возможное значение:
`Strategy Diversity = H / log(7)`, где `H` — энтропия распределения ходов, а `7` — количество колонок игрового поля.
Чем ближе значение к `1`, тем равномернее распределены выбранные ходы между доступными колонками.

Цель оптимизации — максимизация Strategy Diversity.

Таким образом, задача является многокритериальной: необходимо одновременно повышать вероятность победы, уменьшать время принятия решений и увеличивать разнообразие стратегии. При этом улучшение одного критерия не всегда приводит к улучшению остальных.

### 4. Реализация генетического алгоритма NSGA-II

**NSGA-II** — алгоритм многокритериальной оптимизации, который позволяет работать с несколькими критериями независимо друг от друга, не объединяя их в одну числовую оценку.

В отличие от классического генетического алгоритма, NSGA-II сохраняет множество решений, представляющих различные компромиссы между критериями.
В реализации используются следующие основные этапы.

**1. Создание начальной популяции.**

Формируется популяция из `20` случайно сгенерированных особей. Для каждой особи задаются три весовых коэффициента эвристической функции и глубина поиска Minimax.

**2. Оценка особей.**

Каждая особь проверяется в игровых партиях с фиксированным соперником. По результатам вычисляются три критерия: Win Rate, Average Decision Time и Strategy Diversity.

**3. Недоминируемая сортировка.**

Для каждой особи определяется, какие другие решения она доминирует и какими решениями доминируется.
Решение считается доминирующим другое, если оно не хуже него по всем критериям и строго лучше хотя бы по одному критерию.

В результате популяция разделяется на фронты Парето. Первый фронт содержит недоминируемые решения, то есть решения, для которых нельзя улучшить один критерий, не ухудшив при этом хотя бы один другой.

**4. Расчёт Crowding Distance.**

Для поддержания разнообразия решений внутри одного фронта рассчитывается расстояние скученности (Crowding Distance).
Оно характеризует, насколько близко расположены соседние решения в пространстве критериев. Чем больше расстояние, тем более уникальную область пространства занимает особь.

Для граничных решений фронта расстояние принимается равным бесконечности. Это позволяет сохранять крайние варианты компромиссов между критериями.

**5. Выбор родителей.**

Для выбора родителей используется бинарный турнир. Случайным образом выбираются две особи, после чего сравниваются их Pareto Rank и Crowding Distance.
Предпочтение отдаётся особи с лучшим рангом. Если ранг одинаковый, выбирается особь с большим Crowding Distance.

**6. Скрещивание и мутация.**

Из выбранных родителей создаются новые особи.
При скрещивании формируются новые комбинации весовых коэффициентов и глубины поиска. Мутация вносит случайные изменения в параметры, благодаря чему алгоритм может исследовать новые области пространства решений.

**7. Экологический отбор.**

Родительская популяция объединяется с популяцией потомков. Таким образом, получается объединённая популяция из `40` особей.
Для неё повторно выполняется недоминируемая сортировка и рассчитывается Crowding Distance. После этого в новое поколение отбираются `20` лучших особей с учётом ранга и расстояния скученности.

Данный подход позволяет сохранять качественные решения предыдущего поколения и одновременно учитывать новые варианты, полученные в результате эволюции.
Всего было выполнено `10` поколений.

### 5. Результаты работы NSGA-II

В результате работы NSGA-II был получен набор недоминируемых решений. В последнем поколении первый фронт Парето содержал `14` особей из `20`.
Это означает, что алгоритм сохранил несколько вариантов игровых агентов, каждый из которых представляет определённый компромисс между качеством игры, скоростью и разнообразием стратегии.
Для более подробного анализа были выбраны три характерные конфигурации.

**1. Конфигурация с максимальным Win Rate.**

Для демонстрации итоговой конфигурации игрового ИИ была выбрана одна из недоминируемых особей первого фронта Парето.
* веса эвристической функции: `(1.4011, 4.473762, 4.65273)`;
* глубина поиска Minimax: `2`;
* Win Rate: `1.0`;
* среднее время принятия решения: `0.007754` секунды;
* Strategy Diversity: `0.929036`.

Данная конфигурация показала максимальную долю побед среди рассмотренных решений. При этом она обладает небольшой глубиной поиска, что позволяет принимать решения достаточно быстро.
Сравним эту конфигурацию с **baseline**, которую рассматривали в качестве базовой:

* веса эвристической функции: `(2, 3, 4)`;
* глубина поиска: `4`.

**2. Конфигурация с минимальным временем принятия решения.**

* Win Rate: `0.5`;
* среднее время принятия решения: `0.006989` секунды;
* Strategy Diversity: `0.926046`;
* глубина поиска Minimax: `2`.

Данная особь демонстрирует наиболее высокую скорость работы среди рассмотренных решений. Однако её Win Rate ниже, чем у конфигурации с максимальной долей побед.

**3. Конфигурация с максимальным Strategy Diversity.**

* Win Rate: `0`;
* среднее время принятия решения: `0.124446` секунды;
* Strategy Diversity: `0.960427`;
* глубина поиска Minimax: `4`.

Эта конфигурация обеспечивает наибольшее разнообразие выбираемых ходов, однако не показывает хороших результатов по доле побед и скорости принятия решений.

Таким образом, полученные результаты демонстрируют наличие компромиссов между критериями. Нельзя выбрать одну конфигурацию, которая одновременно является лучшей по всем трём показателям.

### 6. Реализация генетического алгоритма Weighted Sum GA

Второй реализованный подход основан на использовании взвешенной суммы критериев.
В отличие от NSGA-II, данный алгоритм объединяет все критерии в одну итоговую оценку — Weighted Score.
Перед вычислением оценки выполняется нормализация критериев, поскольку они имеют разные диапазоны значений и единицы измерения.

Для критериев, которые необходимо максимизировать, используется обычная min-max нормализация. Для времени принятия решения используется обратная нормализация, поскольку его необходимо минимизировать.
После нормализации вычисляется взвешенная сумма:
`Weighted Score = w1 * Win_norm + w2 * Time_norm + w3 * Diversity_norm`, где:

* `w1` — вес критерия Win Rate;
* `w2` — вес критерия Average Decision Time;
* `w3` — вес критерия Strategy Diversity.

Чем выше итоговая оценка, тем предпочтительнее считается особь.
В реализации используются следующие этапы.

**1. Создание начальной популяции.**

Формируется популяция из `20` случайных особей.

**2. Оценка особей и нормализация критериев.**

Для каждой особи вычисляются три критерия. Затем значения нормализуются относительно текущей популяции.

**3. Вычисление Weighted Score.**

Для каждой особи рассчитывается единая взвешенная оценка с учётом заданных приоритетов критериев.
В эксперименте были предусмотрены следующие варианты весов:

* равные приоритеты: `(0.33, 0.33, 0.34)`;
* приоритет Win Rate: `(0.60, 0.20, 0.20)`;
* приоритет скорости: `(0.20, 0.60, 0.20)`.

В рамках проведённого эксперимента использовалась конфигурация с равными приоритетами.

**4. Выбор родителей.**

Для выбора родителей используется бинарный турнир. Случайным образом выбираются две особи, после чего сравниваются их Weighted Score.
Предпочтение отдаётся особи с более высокой оценкой.

**5. Скрещивание и мутация.**

На основе выбранных родителей создаются новые особи. Используются те же операции скрещивания и мутации, что и в NSGA-II.

**6. Отбор нового поколения.**

Родительская популяция объединяется с потомками, в результате чего получается `40` особей.
Для объединённой популяции повторно вычисляются нормализованные критерии и Weighted Score. После этого выбираются `20` особей с наибольшими значениями итоговой оценки.
Процесс повторяется в течение `10` поколений.

### 7. Результаты работы Weighted Sum GA

В проведённом эксперименте использовались равные веса критериев:

`(0.33, 0.33, 0.34)`

Это означает, что все три показателя имеют приблизительно одинаковую значимость при выборе игрового агента.
По результатам работы алгоритма была получена следующая конфигурация:

* веса эвристической функции: `(2.7758, 2.0549, 2.2209)`;
* глубина поиска Minimax: `2`;
* Win Rate: `1.0`;
* среднее время принятия решения: `0.007445` секунды;
* Strategy Diversity: `0.921325`.

Полученное решение показало максимальную долю побед и небольшое время принятия решений. При этом значение Strategy Diversity оказалось несколько ниже, чем у выбранной конфигурации NSGA-II с максимальным Win Rate.

Также стоит отметить, что итоговая популяция Weighted Sum GA оказалась достаточно однородной: все `20` особей имели глубину поиска `2` и Win Rate `1.0`. Различия между ними в основном заключались в значениях весовых коэффициентов и времени принятия решений.
Это свидетельствует о том, что при заданных весах критериев алгоритм сосредоточился на определённой области пространства решений.

### 8. Сравнение NSGA-II и Weighted Sum GA

Оба алгоритма решают одну и ту же задачу, однако используют разные способы оценки и отбора особей.

**NSGA-II** рассматривает каждый критерий отдельно. Благодаря этому он способен сохранять несколько недоминируемых решений, которые отличаются соотношением качества игры, скорости и разнообразия стратегии.

**Weighted Sum GA** преобразует несколько критериев в одну оценку. Это упрощает процесс отбора, однако итоговый результат зависит от выбранных весовых коэффициентов.

Сравним некоторые полученные конфигурации:

| Алгоритм и конфигурация | Win Rate | Average Decision Time | Strategy Diversity |
|---|---:|---:|---:|
| NSGA-II — максимальный Win Rate | 1.0 | 0.007754 | 0.929036 |
| NSGA-II — минимальное время | 0.5 | 0.006989 | 0.926046 |
| NSGA-II — максимальная Diversity | 0 | 0.124446 | 0.960427 |
| Weighted Sum GA | 1.0 | 0.007445 | 0.921325 |

По полученным результатам можно сделать следующие наблюдения:

* Weighted Sum GA нашёл решение с максимальным Win Rate и немного меньшим временем принятия решения, чем выбранная конфигурация NSGA-II с максимальным Win Rate.
* NSGA-II сохранил альтернативные решения, позволяющие выбирать между скоростью работы и разнообразием стратегии.
* Weighted Sum GA сформировал более однородную итоговую популяцию, поскольку все критерии были сведены к одной оценке.
* Результат Weighted Sum GA зависит от выбранных весов. Изменение приоритетов может привести к получению другой конфигурации игрового агента.

Таким образом, нельзя однозначно утверждать, что один алгоритм лучше другого. Выбор подхода зависит от целей оптимизации.

### 9. Вывод

В ходе лабораторной работы были реализованы и исследованы два генетических алгоритма многокритериальной оптимизации: **NSGA-II** и **Weighted Sum GA**.
В качестве объекта оптимизации выступал игровой агент Connect Four, использующий алгоритм Minimax с альфа-бета отсечением. Генетические алгоритмы подбирали параметры эвристической функции и глубину поиска, стремясь улучшить три показателя: долю побед, скорость принятия решений и разнообразие игровой стратегии.

В результате экспериментов оба алгоритма смогли найти конфигурации с Win Rate `1.0` и небольшим временем принятия решений.
При этом были выявлены различия в принципах работы алгоритмов. **NSGA-II** оказался более подходящим для исследования компромиссов между критериями, поскольку формирует фронт Парето и сохраняет несколько альтернативных решений. **Weighted Sum GA** позволяет искать решение с учётом заранее заданных приоритетов, однако его результат зависит от выбранных весовых коэффициентов.

Таким образом, NSGA-II целесообразно использовать в случаях, когда важен анализ различных компромиссов между критериями, а Weighted Sum GA — когда приоритеты критериев известны заранее и требуется получить одно итоговое решение.
